Circle Game Android

Created with: Kotlin.

This is a Android game created in Android Studios using Kotlin. It's a game where the player click on the correct colors to get points, there is two different game modes, time mode & endless mode. As time goes on in a level the spawn rate of the circles is increased. If the player presses three red circles the game is over.

Link to Github: https://github.com/ollin99/circle_game
